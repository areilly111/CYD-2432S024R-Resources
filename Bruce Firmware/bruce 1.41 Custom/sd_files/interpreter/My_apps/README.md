# Custom JavaScript Apps for CYD‑2432S024R 🧩

This directory contains JavaScript applications written by me for use with the CYD‑2432S024R and the Bruce firmware.  
These apps are built from scratch and designed specifically around the hardware limitations and quirks of this CYD variant.

## 🔧 About These Apps

All scripts in this folder are:

- Designed to run within the CYD‑2432S024R’s extremely limited memory  
- Optimized for performance and stability
- Tailored to the unique display, input, and timing behavior of this board  

These apps serve as examples of what can be built natively for this CYD model without relying on modified upstream Bruce apps.

## 📌 Notes

- Some apps may be experimental or minimal due to hardware constraints  
- Additional features and improvements will be added over time  
- Feedback and suggestions are welcome  

## ⚠️ Disclaimer

These applications are original work but are intended to run on firmware derived from the BruceDevices project.  
They are provided **as‑is** for educational, research, and legally authorized testing on hardware you own.  
Use at your own risk.
