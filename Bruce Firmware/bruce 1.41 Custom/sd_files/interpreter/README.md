# SD Files – Bruce JavaScript Apps for CYD‑2432S024R 📁

This directory contains the JavaScript applications that run on the CYD‑2432S024R using the Bruce firmware.  
Because this CYD variant has extremely limited memory, many of these apps have been **heavily modified** to ensure they function correctly.

## 🔧 About These Apps

The `.js` files here include:

- Apps with **new or removed features** to fit memory constraints  
- **Rewritten UI elements** and simplified logic  
- **Optimized code paths** to reduce RAM usage  
- Replacements for components that are incompatible with this CYD model  

Each script has been tested on the CYD‑2432S024R and confirmed to load under the modified Bruce 1.14 firmware.

## 📌 Notes

- Some apps differ significantly from their original Bruce versions  
- Certain features may be intentionally removed due to hardware limitations  
- Additional ports and optimizations will be added over time
