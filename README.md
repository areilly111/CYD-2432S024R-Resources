## CYD‑2432S024R Resources 🔧

This repository contains my work on the **CYD‑2432S024R**, a rare CYD variant with very little public documentation. Since information on this board is hard to find, I’ve started building a collection of tools, notes, and working examples to help others experimenting with this hardware.

## 📘 What’s Inside

## 🔹 Customized Bruce 1.14
A modified build of **Bruce 1.14** tailored specifically for the CYD‑2432S024R’s extremely limited memory.  
This version removes unnecessary components and adjusts behavior to ensure stable operation on this board.

## 🔹 Ported Bruce JavaScript Apps
I’m actively porting the default Bruce `.js` apps to run correctly on this CYD variant.  
Because the board has very little RAM, each port includes memory‑saving tweaks and compatibility fixes.

## 🔹 Additional Resources
As I continue exploring this board, I’ll add:
- Hardware notes  
- Pinout references  
- Memory‑optimized utilities  
- Example configurations  
- Any quirks or undocumented behaviors I discover

- Provide working examples for anyone using the CYD‑2432S024R
